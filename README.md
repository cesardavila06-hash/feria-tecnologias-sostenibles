# Feria de Tecnologías Sostenibles

Feria virtual en 3D con el catálogo de casos de éxito de tecnologías industriales sostenibles, organizada por pabellones (Alemania, España, Italia, Suiza y Finlandia).

- `index.html`: la página (recorrido 3D, pabellones y fichas de cada empresa).
- `data/catalogo.json`: todos los datos. Para agregar una empresa, completa un stand con los campos de `_plantilla_stand` y cambia su `estado` a `ocupado`.
- `img/`: logos y fotos.

Publicado con GitHub Pages desde la rama `main`.
